# 금요일 마감 돌파 매매 (Friday Close Breakout) — 기획서

> 상태: **P0~P3 구현 완료 (2026-10-12), P4 실주문은 범위 밖.** P0 일봉 대리 백테스트 판정은 **'조건부'** — 총수익은 대조군보다 높지만 왕복 비용 0.75% 에서 순손실(손익분기 0.63%). 분봉 성과는 포워드 기록으로 쌓는 중. 상세 수치·구현은 `CLAUDE.md` "금요일 마감 돌파" 절 참고.
> 구현 위치 변경: 대리 백테스트는 `friday.py` 가 아니라 `screener/friday_backtest.py` 로 분리했다. 계획과 달라진 점: 과거 분봉이 부족하면 일평균으로 근사하지 않고 제외, 포착 창 비교는 15:00 이전/이후 집계로 대체.
> 출처: 유튜브 '수익탐정사무소' (데빈 베이커 인터뷰 요약). 영상 주장은 **근거 수치가 없는 일화**이므로 그대로 믿지 않고 가설로만 취급한다.

## 1. 이런 매매법이 있나?

- **있다.** 주말 오버나이트(weekend/overnight) 보유, 장 마감 직전 수급 쏠림(late-day momentum), "종가 베팅" 이라 불리는 계열이다.
  한국 단타에서도 '종가 베팅 → 다음날 시초 갭 매도' 가 흔한 패턴이다.
- **다만 "금요일이라서 특별히 유리하다"는 증명된 사실이 아니다.** 학계에는 오버나이트 수익률 프리미엄, 장 막판 30분 수익률의
  당일 첫 30분 예측력(intraday momentum) 연구가 있으나, 요일 효과는 시장·기간에 따라 부호가 바뀐다.
- 영상은 **미국장** 맥락이다. 한국장은 구조가 달라 그대로 옮기면 안 된다 (다음 절).

## 2. 한국장 적용 시 달라지는 점

| 항목 | 미국 (영상) | 한국 (이 프로젝트) |
|---|---|---|
| "마감 30분 전" | 15:30 ET | **15:00 KST** |
| 마감 직전 | 연속 매매 | **15:20~15:30 종가 단일가(동시호가)** — 주문은 가능하나 체결가가 일괄 결정, 돌파 추격 불가 |
| 가격 제한 | 없음 | ±30% (월요일 갭의 상한/하한이 있음) |
| 주말 리스크 | 뉴스·갭 | 동일 + 미국장 금요일 야간 변동이 월요일 시초에 반영 |
| 시간외 | 있음 | 시간외 단일가·NXT 존재 — 월요일 장전(NXT) 반응이 먼저 나올 수 있음 |
| 1분봉 시각 | – | 토스 1분봉은 **봉 종료 시각 라벨**, 종가 동시호가 봉은 `15:30/15:31` (CLAUDE.md "토스 1분봉 시각 규칙") |

→ 한국 버전의 포착 창은 **14:30~15:15**, 진입 판단 마감은 **15:15** (동시호가 전). 15:20 이후 체결 로직은 쓰지 않는다.

## 3. 전략 정의 (가설)

> "일주일간 조용하던 종목이 금요일 마감 무렵 거래량을 동반해 당일 고점을 뚫는다 → 주말을 넘길 큰 자금이 들어온 것 → 월요일 갭상승."

### STEP 1 — 조용한 주 (일봉, 월~목 4영업일 + 직전 주)
- 최근 5영업일 `(최고가-최저가)/종가` ≤ **A%** (기본 후보 12%) — 변동성 수축.
- 최근 5일 일평균 거래량이 20일 평균의 ≤ **B배** (기본 후보 1.0) — 거래 한산.
- 종가 > MA20 또는 바닥권 아님 필터는 **백테스트로 선택** (초기엔 넣지 않는다).

### STEP 2 — 금요일 마감 돌파 (분봉, 14:30~15:15)
- 금요일 당일 누적 거래량이 **같은 시각까지의 과거 5영업일 평균 누적**의 ≥ **C배** (후보 2.0).
  → `supply.py` 의 `minute_profile`·"과거 같은 분까지 누적 평균" 로직 재사용.
- 현재가가 **당일 고가 갱신** (14:30 이전 고점 돌파) AND 현재가 > 당일 VWAP.
- 최근 30분 거래량이 직전 30분보다 증가, 틱 규칙 매수 비중 ≥ 55% (`tick_flow`).
- 유의종목(투자경고·정리매매·VI 등) 차단 — 세력추정과 같은 `blocking_warnings`.

### STEP 3 — 시장 필터
- KOSDAQ/KOSPI 지수 종가(현재가) > MA20 (`regime.py` 재사용). 이탈이면 제외 또는 감점.
- 금요일 당일 지수 −1% 이하 급락 시 제외 후보 (백테스트로 확인).

### 청산 규칙 (가설)
- **월요일 시초~09:30 사이 분할 청산**이 기본. 갭상승이 없으면 손실 제한 우선.
- 손절: 금요일 당일 VWAP 또는 돌파 직전 지지선 이탈 (월요일 시초가가 그 아래면 시초 즉시 청산).
- 시간 손절: 월요일 장 마감까지 반등 없으면 종가 청산 (이후 보유는 이 전략 범위 밖).

## 4. 검증 우선 — 만들기 전에 이것부터

이 프로젝트의 원칙(백테스트 근거 없는 전략은 그렇다고 명시)을 따른다. 분봉 이력은 토스 API에서 길게 못 받으므로 **2단계로 검증**한다.

### 4-1. 일봉 대리 백테스트 (즉시 가능, 3년·2,500종목 일봉 캐시 활용)
분봉 없이 **가설의 핵심 경제성**만 먼저 본다.
1. 금요일 일봉 중 `종가 ≥ 고가 × 0.98`(고가 부근 마감) AND `거래량 ≥ 20일 평균 × 2` AND 직전 4일 변동성 수축 → 대리 신호.
2. 수익 = **금요일 종가 → 월요일 시가** (갭), 비용 0.15% + 슬리피지 0.3% 차감 (기존 백테스트 가정과 동일).
3. 비교군 (필수): ① 같은 조건의 **월~목** 신호의 다음날 시가 갭, ② 무조건 금요일 종가 매수 → 월요일 시가, ③ 시장 국면별 분할.
4. 판정 기준: 비교군 대비 평균 수익이 비용을 넘고, 연도별·국면별로 부호가 일관해야 통과.
   금요일 효과가 비교군(월~목)과 차이 없으면 **'금요일' 이라는 전제를 버리고** 일반 '종가 강세 → 익일 갭' 전략으로 재정의한다.
- 한계: 일봉 고가 부근 마감은 15:00 돌파와 다르다. 낙관/비관 편향을 결과표에 병기한다.
- 구현 위치: `screener/backtest.py` 와 별도 `screener/friday.py` 의 `friday_proxy_backtest()` (기존 `Backtester` 를 건드리지 않음).

### 4-2. 분봉 포워드 기록 (관찰)
- 매주 금요일 14:30~15:15 스캔 결과를 `out/friday_signals.jsonl` 에 적재 (종목·시각·가격·거래량배수·점수).
- **월요일 시가·09:30·종가를 자동 채워** 결과 표를 만든다. 10~12주(표본 약 100건 이상) 쌓이기 전에는 실주문 금지.
- 분봉 백테스트는 이 기록이 쌓인 뒤 가능하다 (과거 분봉이 API로 충분하지 않음).

## 5. 구현 설계 (검증 통과 시)

수급포착매매(`/supply`)와 **같은 구조**로 만든다 — 관찰용 스크리너, 주문 없음, 백테스트 전엔 문구를 단정적으로 쓰지 않는다.

| 항목 | 내용 |
|---|---|
| 모듈 | `screener/friday.py` — `FridayConfig`, `evaluate`, `FridayScanner`, `FridayService` |
| 후보 | `rankings MARKET_TRADING_AMOUNT` 상위 100 + 메타 필터(ETF·우선주·거래정지 제외) — `supply.py` 후보 로직 재사용 |
| 재사용 | `session_bars`, `vwap`, `tick_flow`, `minute_profile`, `regime.MarketRegime`, 유의종목 목록 |
| 실행 시간 | **금요일 14:30~15:15 만 1~2분 주기**, 그 외 시간엔 대기(공휴일 연휴 전 마지막 영업일도 대상으로 확장 — 휴장일 캘린더 필요) |
| 화면 | `/friday` (GNB 4번째, 가칭 "주말 마감 매매"). AG Grid + 당일 분봉 SVG(고점·VWAP 표시), 오프캔버스 상세 |
| API | `GET /api/friday/state`, `POST /api/friday/scan`, `GET /api/friday/chart/{symbol}` |
| CLI | `python main.py friday` |
| 알림 | 초기엔 화면 확인만 (수급포착과 동일 방침). 이후 필요 시 텔레그램/이메일 |
| 설정값 | 임계값(A,B,C 등)은 코드에 흩뿌리지 말고 `FridayConfig` 한 곳에만 |

### 점수 (초안, 경험칙 → 포워드 기록으로 재산정)
거래량 배수 25 · 변동성 수축 20 · 고가 돌파 신선도(마지막 돌파 후 경과) 15 · 매수 비중 15 · VWAP 이격 10 · 시장 국면 15.
**실측 근거가 생기기 전에는 컷오프를 '검증된 값'이라 쓰지 않는다.**

### 실주문 (맨 마지막 단계, 별도 승인)
- 기본 **금지**. 포워드 기록으로 기대값이 확인되면 그때 검토.
- 허용하더라도 기존 게이트 유지: 서버 `TOSS_TRADING_ENABLED` + 사용자 `trading_opt_in` + 별도 live 스위치, 1회 한도, 정규장(15:15 이전 진입) 한정.
- 주말 보유 갭 리스크는 손절이 월요일 시초가에서 **갭하락으로 건너뛰어질 수 있어** 손절선만큼 잃는다는 보장이 없다 → 포지션 크기를 세력추정보다 보수적으로.

## 6. 리스크 · 한계 (문서·화면에 반드시 표기)

1. 영상 주장 자체가 미검증이며 미국장 기반이다. 한국장 효과는 모른다.
2. 마감 직전 돌파는 **물량 떠넘기기(가짜 돌파)** 일 수 있고, 월요일 시초 갭하락이 곧바로 올 수 있다.
3. 지수 하락 국면에서 효과가 사라질 가능성이 높다.
4. 주말 동안의 뉴스·공시·미국 야간장은 통제할 수 없고, 이 시스템에 공시/뉴스 API 가 없다 — 사람이 확인해야 한다.
5. 15:20 이후 단일가 구간은 돌파 추격이 불가능해 진입 창이 짧다 (실질 45분).
6. 틱 규칙 매수세는 추정치다 (HTS 체결강도와 다름).
7. 표본이 금요일 주 1회뿐이라 포워드 검증에 시간이 오래 걸린다.

## 7. 단계별 로드맵

| 단계 | 산출물 | 완료 기준 |
|---|---|---|
| P0 | 일봉 대리 백테스트 (`friday_proxy_backtest`) + 결과표 | 비교군 대비 우위 유무 판정. **우위 없으면 여기서 중단/재정의** |
| P1 | `friday.py` 스캐너 + `main.py friday` + 금요일 신호 JSONL 기록 | 단위 테스트(외부 API 불필요), 금요일 라이브 1회 관찰 |
| P2 | `/friday` 화면 + API + GNB 추가 | 수급포착 화면과 동일 UX, 세션/서버 스캐너 선택 규칙 준수 |
| P3 | 월요일 결과 자동 채움 + 주간 리포트 | 10~12주 누적 후 승률·평균 수익·MDD 산출 |
| P4 | (선택) 실주문 연동 검토 | P3 기대값이 비용을 넘고 장기간 안정적일 때만 |

## 8. 결정이 필요한 항목

- 연휴 전 마지막 영업일(예: 추석·설 직전)도 '금요일 마감' 으로 볼 것인가? (권장: 포함, 단 별도 표시)
- 초기 화면을 새 메뉴(`/friday`)로 둘지, 수급포착 화면의 탭/필터로 시작할지. (권장: 검증 전엔 **CLI + JSONL 기록만**, 화면은 P2)
- 포착 창을 14:30 으로 시작할지, 영상대로 마감 30분 전(15:00)으로 할지. 두 창을 모두 기록해 비교 권장.
